# Pulse Atlas

A premium cardiac wellness visualization written entirely in Ruby. Its central heart is a
full-panel image rendered through the framework's `image` component. The app also combines live
ECG-style charting, radial gauges, particles, a recovery heatmap, scheduled state, breathing
controls, and an image-backed insight dialog. It is a UI showcase, not medical advice.

```bash
zui run main.rb
```
