# Tesla Drive Lab

A Tesla-inspired electric-vehicle center display written entirely in Ruby. Its three-column dark
cockpit composition is informed by MDITY Agency's “Tesla | Car UI / Dashboard” study while using
original vehicle artwork and a Ruby-drawn map. It combines a vehicle/speed cluster, emergency and
camera controls, climate and seat controls, battery and route telemetry, live navigation, and a
real local-audio media player. Drive, Autosteer, lock, trunk, charge port, temperature, seat heat,
media, route, battery, range, traction, and trip state all update the simulation. The full-width
vehicle viewport stacks controls over the artwork, cycles rear/front/profile views, shows dedicated
open-trunk and open-charge-port imagery, and adds animated road motion while driving. It also
exercises generated PNGs, canvas, gauges, charts, switches, dialogs, bindings, and scheduled telemetry.
This is an unofficial framework showcase and is not affiliated with Tesla or MDITY Agency.

Design reference: https://dribbble.com/shots/23396081-Tesla-Car-UI-Dashboard

```bash
zui run main.rb
```
