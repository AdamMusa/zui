# Image asset provenance

`assets/future-pour-bar.jpg` is original AI-generated artwork created for this repository on
2026-08-23 with OpenAI's built-in image generation tool. The production prompt requested an
unbranded, futuristic restaurant bar lineup of water, sparkling water, soda, juice, and iced tea,
with no people, logos, labels, text, or watermark. It was resized and encoded as a 1600×743 JPEG
for compatibility with common Qt image decoder installations. A WebP encoding is retained beside it
as a decoder-compatibility fixture, but the application intentionally loads the JPEG.
