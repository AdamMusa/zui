# Stratos

An orbital weather command center written entirely in Ruby. Visible, Infrared, and Moisture layers
drive real GPU brightness, saturation, colorization, and particle changes over the generated storm
image. The live scan can pause/resume, telemetry advances only while scanning, and briefing/share
actions update operational state. It also exercises radar and area charts, heatmaps, scheduled
state, and an image-backed public briefing dialog.

```bash
zui run main.rb
```
